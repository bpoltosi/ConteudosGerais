# Conteúdos Gerais

Repositório de materiais de estudo e arquivos de apoio de diferentes disciplinas e atividades, organizado por assunto.

## Conteúdo atual

### Modelagem 3D

A pasta [Modelagem3D/](Modelagem3D/) reúne arquivos compactados de desafios do HackaTruck e um README específico para os materiais.

### Redes de Comunicação

A pasta [RedesDeComunicação/](RedesDeComunicação/) reúne atividades e registros relacionados a redes, incluindo:

- Exercícios de aula em arquivos de texto.
- Atividade prática de endereçamento IP.
- PDF com o enunciado da atividade.
- Capturas de tela e evidências de configuração/diagnóstico de rede.

## Finalidade

Centralizar materiais acadêmicos, exercícios, arquivos de referência e evidências práticas que não pertencem diretamente a um repositório de implementação de software.

## Organização

Novas disciplinas podem ser adicionadas em diretórios próprios, mantendo os arquivos e referências agrupados por tema.

## Status

Acervo de estudos em atualização contínua.
